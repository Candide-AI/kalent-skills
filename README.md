# kalent-skills

Skills you install into an AI agent. The install command picks the one you need.

| Skill | What it is for | Install |
| --- | --- | --- |
| `build-with-kalent` | Call the Kalent HTTP API from a coding agent | `npx skills add Candide-AI/kalent-skills --skill "build-with-kalent"` |

The install command picks the skill, so later skills can live in the same repo.
